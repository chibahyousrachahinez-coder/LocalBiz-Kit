## How to Access & Launch LocalBiz Kit

LocalBiz Kit is built as a fast, clean, modern web application designed to run locally in any web browser.

### Option 1: Access via Live Web App URL
Use the direct access link provided on your Payhip download page:
- Bookmark the application in your browser bar for quick daily access.
- Works smoothly on Google Chrome, Apple Safari, Mozilla Firefox, and Microsoft Edge.
- Fully responsive on desktop computers, laptops, iPads/tablets, and mobile phones.

### Option 2: Running from Local Source / Offline Folder (If Downloaded as an Archive)
If you received the source bundle:
1. Ensure you have Node.js (version 18 or newer) installed on your machine.
2. Open your terminal in the application root directory.
3. Run `npm install` to install local dependencies.
4. Run `npm run dev` to start the local server.
5. Open `http://localhost:3000` in your web browser.
6. The app will run 100% locally on your machine with zero internet connection needed.

## Important Data Privacy & Safety Notice

- **No Remote Tracking or Cloud Storage**: LocalBiz Kit saves your data directly inside your browser cache (`localStorage` and `IndexedDB`). No private business data or draft customer replies are sent to external servers.
- **Regular Backups**: Because data lives in your browser, **always export a JSON backup** (`Settings > Export JSON Backup`) periodically or before clearing your browser cache.
- **Offline Capability**: You can write posts, prepare offers, and draft replies even while offline on a flight or during internet outages.
